Projektbeschreibung

Du kennst deine Bedarfe noch nicht genau? Beschreibe ein Projekt, das deine Organisation umsetzen möchte, und lass dir daraus Bedarfe generieren. Sie werden unten in den passenden Kategorien ergänzt, bereits eingetragene Bedarfe bleiben erhalten. Du kannst sie anschließend wie gewohnt bearbeiten und speichern, auch für mehrere Projekte nacheinander. Die Projektbeschreibung selbst wird nicht gespeichert.
